# Admin tasks — route non-research work

The L2 admin track. Admin does NOT go through the research loop — it has its own home and tools.
Keep this thin: identify the work, point to the right place, record any strategic decision.

## Route
- Grants / fellowships / HDR / reporting → the cloud-docs `organisation/` area (see `~/hub/config.yml`
  `paths.onedrive_docs`).
- Existing ops agents already built by the user: safe-work-procedure conversion; the
  Outlook/Teams/Planner task digest. Hand off to those rather than rebuilding.
- Teaching / meetings → the user's normal tools.

## Record
- Strategic admin decisions (priorities, deadlines) → log via `decide` to the hub log
  (e.g. "grant before glioma paper until <date>").

Do not analyse data here. Wet-lab work stays in LabArchives (out of scope).
